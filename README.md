# bio-counter — воркер со счётчиком просмотров

Один проект Cloudflare Worker: отдаёт статику сайта **и** считает просмотры.
Адрес остаётся прежним — `https://solitary-mouse-58d1.tkornusenkov.workers.dev`.

```
public/          файлы сайта, попадают в корень сайта
src/index.js     воркер: /api/count и /api/reset, остальное — статика
wrangler.toml    конфиг: имя воркера, привязка KV, папка статики
```

## Разовая настройка

```
cd C:\Users\tkorn\Downloads\bio-counter

npx wrangler login
npx wrangler kv namespace create VIEWS
```

Команда выведет строку вроде

```
[[kv_namespaces]]
binding = "VIEWS"
id = "a1b2c3d4e5f6..."
```

Впиши её `id` в `wrangler.toml` вместо `ВСТАВЬ_СЮДА_ID_ИЗ_ВЫВОДА_КОМАНДЫ`.

Если `npx wrangler deploy` спросит, что делать с уже существующим проектом
`solitary-mouse-58d1` — согласись. Пока деплой не прошёл, старый сайт продолжает
работать: замена атомарная.

Затем задай токен для сброса счётчика:

```
npx wrangler secret put RESET_TOKEN
```

Введи любую длинную строку. В файл она не попадает, живёт только в секретах.

## Дальше — каждый деплой

```
npx wrangler deploy
```

Загрузит и код, и статику. Перетаскивать файлы в панель Cloudflare больше не
нужно.

## Счётчик

| Запрос | Что делает |
| --- | --- |
| `GET /api/count?v=<id>` | отдаёт число, новому браузеру увеличивает на 1 |
| `POST /api/reset` + `X-Reset-Token` | сбрасывает на `INITIAL_COUNT` |

Считаются уникальные посетители: id лежит в `localStorage`, сервер помнит его
год. Перезагрузка страницы и переходы туда-обратно число не меняют — чтобы
проверить рост, открой сайт в приватном окне или сбрось счётчик.

Если счётчик упал или `/api/count` не отвечает, страница показывает 623.
Число красивое, живым оно становится только после первого деплоя.

Начальное значение — в `wrangler.toml`, поле `INITIAL_COUNT`. После первого
захода значение лежит в KV, и эта настройка больше не участвует.

### Ограничение

KV в Cloudflare читается «в конечном счете». Два одновременных запроса от разных
новых посетителей теоретически могут записать одинаковое значение и потерять
единицу. Для bio-страницы это незаметно. Если нужна точность — перевести на
Durable Objects, тогда нужен отдельный класс и привязка.

## Отладка

Сайт по-прежнему показывает диагностику по `?debug=1` — панель с проверкой
кодеков, автозапуска видео и состоянием сети.

Счётчик проверить можно напрямую:

```
https://solitary-mouse-58d1.tkornusenkov.workers.dev/api/count
```

Вернётся `{"count":624}`. Два запроса подряд дадут одно и то же число — так и
должно быть, браузер один и тот же.
